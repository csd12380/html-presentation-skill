# 环境态动效库

页面不翻页时持续运动的可选清单。**40 种动效 + 一套参数变量**，每页从里面挑 3–4 个组合，不是全开。代码在 `templates/环境态动效.css`，整段粘进页面即用。

> **默认参数以「肉眼明显看得出在动」为准。** 早期版本用 48s 推镜 + 1.5% 位移，1 秒只走 0.6px，像素差能测到但人眼完全看不见 —— 那是错的，已全部重设。别再把幅度调回"极轻微"，也别把周期拉到 30s 以上。

## 一、参数系统

所有动效共用下面这组变量，改一处全场生效。想调快就把周期整体乘 0.7，想让运动更明显就调 `--amp-*` 和 `--zoom-*`，不用去改 40 条 `@keyframes`。

| 类别 | 变量 | 默认值 | 用途 |
|---|---|---|---|
| 启动 | `--idle-start` | 1.6s | 等最长入场动画跑完再开始；小于入场时长会打架 |
| 周期 | `--t-blink` | 1.1s | 光标闪烁，仅封面 |
| | `--t-fast` | 5s | 呼吸、脉动、环形、波浪 |
| | `--t-mid` | 8s | 光斑、浮动、光带、线条 |
| | `--t-med` | 11s | 明暗、倾斜、溶解、环绕 |
| | `--t-slow` | 14s | 平移、噪点、星点、跑马灯 |
| | `--t-slower` | 18s | 推镜、图片缓移、视差 |
| | `--t-glacial` | 23s | 拉远、网格 |
| | `--t-rotate` | 28s | 缓转 |
| 位移 | `--amp-xs` / `--amp-s` / `--amp-m` / `--amp-l` | 1.5% / 3% / 5% / 9% | 全幅层 1% ≈ 19px，5% ≈ 96px |
| | `--amp-flow` | 18% | 光幕流动专用 |
| 缩放 | `--zoom-s` / `--zoom-m` / `--zoom-l` | 1.10 / 1.18 / 1.30 | 推镜、脉动 |
| 明度 | `--dim-hi` / `--dim-lo` | 1 / .58 | 整体明暗呼吸区间，跨度 0.42 |
| | `--glow-lo` / `--glow-hi` | .14 / .88 | 光斑明暗区间，跨度 0.74 |
| 文字 | `--rise` / `--rise-wave` | 10px / 16px | 标题浮动、逐字波浪，用 px 不用 % |
| 环绕 | `--orbit-r` | 60px | `.ib-orbit` 半径，小元素必须用 px |
| 相位 | `--ph-1` / `--ph-2` / `--ph-3` | 1.1s / 2.3s / 3.7s | 同类加 `.ph1/.ph2/.ph3` 错开起步 |
| 缓动 | `--idle-ease` | ease-in-out | 全场统一，不混用第二条曲线 |

周期取 5/8/11/14/18/23/28 是刻意错开的：没有小的公共倍数，画面不会周期性一起复位。

**可见性换算**（改参数前先算这笔账）：一个 18s 周期、`--zoom-m` 1.18 的推镜，前半程 9s 放大 18%，平均每秒 2%；而旧版 48s / 1.07 是每秒 0.15%。差 13 倍。人眼能察觉的运动门槛大约是**每秒 1% 以上**——低于这个数就等于静止。

## 二、三速节奏

每页从下面三层各挑一个，凑成 **3–4 个动效**；其中 F 层至少一个当主运动。

| 速度层 | 周期 | 承担什么 | 典型类 |
|---|---|---|---|
| 慢速铺底 | 14–28s | 背景推镜、平移、网格，整幅画面在缓慢移动 | `.ib-bg-push` `.ib-bg-panx` `.ib-grid` `.ib-spin` |
| 中速氛围 | 8–11s | 光斑、明暗、光带、图片倾斜，明显看出光影变化 | `.ib-glow` `.ib-sweep` `.ib-dim` `.ib-img-tilt` `.ib-maskflow` |
| 快速点题 | ≤5s | 标题、光晕、环形、波浪，抓注意力 | `.ib-text` `.ib-halo` `.ib-ring` `.ib-wave` |
| **强可见主运动** | 8–14s | 大面积光柱 / 粒子 / 光幕，一眼看见在动 | `.ib-beam` `.ib-particles` `.ib-maskflow` |

同层挑两个会互相抢注意力，但**不同层叠 3–4 个是必要的**——只有一两个小装饰环在动，整体仍像静态图。

## 三、动效清单（40 种）

### A 背景层 8 种 · 挂在全幅背景图或背景容器上，容器必须 `overflow:hidden`

| 类 | 效果 | 周期 | 幅度 | 备注 |
|---|---|---|---|---|
| `.ib-bg` / `.ib-bg-push` | 推近 + 上移 | 18s | scale→1.18，上移 3% | 最常用，基础类 |
| `.ib-bg-pull` | 从放大状态拉远 | 23s | 1.30→1.00 | 适合开场封面 |
| `.ib-bg-panx` | 水平往返平移 | 14s | ±5% | **图要比容器宽 15%**，否则露边 |
| `.ib-bg-pany` | 垂直往返平移 | 14s | ±5% | 竖构图照片 |
| `.ib-bg-drift` | 四方向画圈漂移 | 18s | 3%–5% | 最自然，不露往复感 |
| `.ib-bg-turn` | 钟摆旋转 | 28s | ±3.5°（放大 1.14 防露边） | 比旧版 ±1.2° 明显得多 |
| `.ib-bg-cross` | 上层图交替淡出 | 11s | opacity 1→0 | 要准备两张同机位图 |
| `.ib-bg-para-back` + `-front` | 双层反向平移做视差 | 18s / 14s | 9% / 3% | 成对使用，前后层速度不同 |

### B 光影氛围层 7 种 · 挂在绝对定位的渐变/纹理/遮罩层上

| 类 | 效果 | 周期 | 备注 |
|---|---|---|---|
| `.ib-glow` | 光斑明暗 + 位置漂移 | 8s | opacity .14→.88，位移 5%，基础类 |
| `.ib-halo` | 光晕脉动 + 缩放 | 5s | opacity .14→.88，scale→1.10 |
| `.ib-sweep` | 一道光带横向扫过 | 8s | -150%→150%，opacity .9，比旧版快 1.6 倍 |
| `.ib-dim` | 整层明暗呼吸 | 11s | 1→.58，跨度够大才看得见 |
| `.ib-vignette` | 暗角脉动 | 11s | opacity .30→.92 + 缩放 |
| `.ib-grain` | 噪点/颗粒层游走 | 14s | 纹理层要比画布大 |
| `.ib-grid` | 网格线平移 | 23s | ±3%，层设 `inset:-8%` 防露边 |

### C 图片主体层 7 种 · 挂在裁切框内部的 `<img>` 上，框要 `overflow:hidden`

| 类 | 效果 | 周期 | 备注 |
|---|---|---|---|
| `.ib-img` | 推近 + 斜向缓移 | 18s | scale→1.10，位移 5%，基础类 |
| `.ib-img-pan` | 图片内部水平往返 | 14s | ±3% + 常态放大 1.14 防露边 |
| `.ib-img-tilt` | 3D 倾斜摆动 | 11s | ±6°，给建筑/产品图 |
| `.ib-img-window` | 开窗式缩放 | 14s | 1.00→1.10，配合拱形/圆形裁切 |
| `.ib-img-cross` | 双图叠印交替 | 11s | 同 `.ib-bg-cross`，两张同主体不同光线 |
| `.ib-img-float` | 图片整体上下浮 | 8s | 1.5%→-3%，约 48px 行程 |
| `.ib-img-zoomx` | 仅横向拉伸 | 18s | 会变形，只用于抽象背景图 |

### D 文字层 6 种 · 挂在标题内层的 `<span>` 上

| 类 | 效果 | 周期 | 备注 |
|---|---|---|---|
| `.ib-text` | 标题呼吸（上浮 10px） | 5s | 基础类，opacity 1→.84，**正文禁用** |
| `.ib-float` | 标题上下浮动 | 8s | 4.5% 行程 |
| `.ib-shimmer` | 明暗微闪 | 8s | opacity 1→.55，不移动位置 |
| `.ib-caret` | 光标闪烁 | 1.1s | 只用于封面 / 打字机效果 |
| `.ib-stagger` | 逐字错峰呼吸 | 5s | 每字一个 span，写 `style="--i:0..N"` |
| `.ib-tick` | 装饰性数字 6px 轻跳 | 5s | 只给装饰编号，**不给要读的数据** |

`.ib-text` `.ib-float` `.ib-stagger` `.ib-tick` `.ib-shimmer` `.ib-wave` 在 CSS 里已统一设 `display:inline-block`。行内元素的 `transform` 不生效，自己手写时别漏这条。

**文字可读性的边界**：标题可以到 10–16px 位移，但**正文、图注、页码、数据标签一律不加环境态**。大幅动的是背景、图片、光效和装饰，不是正文。

### E 装饰图形层 6 种 · 挂在 SVG / 线条 / 编号 / 卡片上

| 类 | 效果 | 周期 | 备注 |
|---|---|---|---|
| `.ib-spin` | 匀速旋转 | 28s | 基础类，旧版 90s 转一圈等于不动 |
| `.ib-spin-rev` | 反向旋转 | 28s | 和 `.ib-spin` 配对做双环 |
| `.ib-line` | 线条伸缩 + 明暗 | 8s | scaleX→1.28，`transform-origin` 设左端 |
| `.ib-ring` | 环形脉动 | 5s | scale→1.10，opacity .25→.95 |
| `.ib-dots` | 星点 / 粒子层漂移 | 14s | 位移 5%，整层移动 |
| `.ib-marquee` | 竖排编号滚动 | 14s | **内容必须复制两遍**，滚到 -50% 才接得上 |

### F 强可见层 6 种 · 专门解决「动了但看不见」

| 类 | 效果 | 周期 | 挂在什么上 |
|---|---|---|---|
| `.ib-beam` | 斜向宽光柱横扫全屏 | 8s | 一个宽 30–40%、斜切渐变的绝对定位 div |
| `.ib-particles` | 粒子层整体上浮循环 | 14s | 点阵/星点层，从 +8% 飘到 -18% 并淡出 |
| `.ib-maskflow` | 大面积光幕左右流动 | 11s | 径向渐变层，位移 ±18%，opacity .35→.95 |
| `.ib-edge` | 描边走光 | 8s | 细线 / 边框条，scaleX→1.35 |
| `.ib-wave` | 逐字波浪（幅度 16px） | 5s | 每个字一个 span，写 `style="--i:0..N"` |
| `.ib-orbit` | 元素绕小圈公转 | 11s | 圆点、图标、角标，半径 `--orbit-r` 默认 60px（**必须用 px**：transform 百分比相对元素自身尺寸，22px 的圆点配 5% 只有 1px 行程，等于没动） |

F 层每个都覆盖大面积或做大幅位移，**每页至少用一个**。只靠 `.ib-grid` + `.ib-dim` + `.ib-ring` 这种"淡网格 + 明暗 + 小圆环"的组合，验活能过但肉眼几乎看不到，属于不合格。

## 四、组合规则

1. **每页 3–4 个动效**，慢速 / 中速 / 快速各一个，再加一个 F 层强可见主运动。上限 5，超过就互相抢戏。
2. **同一个元素只挂一个 `.ib-*` 类**，且外面必须包一层负责入场的 `.a`。两套 `transform` 动画放一个元素上会互相覆盖。
3. **相邻两页不重复同一套组合**。11 页里至少用上 8 种不同的搭配，跟图片融入方式一样，不能全篇一个套路。
4. **同类多个元素用 `.ph1/.ph2/.ph3` 错开起步**，比如三张卡片都浮动，第二张加 `.ph1`、第三张加 `.ph2`。
5. **文字只给大标题**，正文、图注、页码、数据标签一律不加环境态。
6. **讲解页、交互页、数据页也要有主运动**，只是把 F 层放在背景（光幕/光柱），不动数字和说明文字。以前"减配到只剩淡网格"是错的。

## 七、性能与禁用清单

- **只动 `transform` 和 `opacity`。** 动 `width/height/filter/box-shadow/background-position/letter-spacing` 会触发重排或重绘，投影机上直接掉帧。
- **一页最多 5 个合成层。** 每个 `.ib-*` 都带 `will-change`，开太多会吃显存；翻走的页会自动收回。
- **`.ib-caret` 不进正文**，1.1s 的闪烁在文字旁边很刺眼。
- **`.ib-tick` 不给真实数据**，数字跳动会让人怀疑读数。
- **交叉溶解类**（`.ib-bg-cross` `.ib-img-cross`）必须是同一个主体、同一机位的两张图，否则会出现"两张不同的楼在闪"。
- **平移类要留余量**：`.ib-bg-panx/.ib-bg-pany/.ib-img-pan` 的图比裁切框宽/高 15%，否则移到端点会露出底色。
- **位移百分比相对元素自身尺寸**：`--amp-*` 用在全幅层是几十上百像素，用在 22px 的小圆点上只有 1px，等于没动。小元素一律改用 px 变量（`--rise` / `--rise-wave` / `--orbit-r`），或把它放大成整层。
- **系统开了"减少动态效果"**：CSS 里 `prefers-reduced-motion` 会全部停下，无需额外处理。
- **翻走重置、回来重播**：所有动画挂在 `.slide.on` 下，`.on` 移走即停，回来从 0% 重播，不需要 JS。
- **静止态预置**：CSS 末尾已把 0% 不是"静止状态"的类预先设好静态值，避免入场结束瞬间跳变。改幅度时这一段必须同步改。

## 八、自检

`scripts/check.py` 会在入场结束后隔 2.0s 截两帧比对像素差，并扫描每页动效的周期与种类，输出三档判定：

| 等级 | ratio | 含义 | 处理 |
|---|---|---|---|
| 静止 ⚠ | < 0.002 | 页面根本没动 | 补 `.ib-*`，检查 `inline-block` |
| 微动不可见 ⚠ | 0.002–0.012 | 测得到但肉眼看不出 | **按不合格处理**，加 F 层强可见动效或调大幅度 |
| 明显可见 ✅ | ≥ 0.012 | 人眼能察觉 | 通过 |

脚本还会报出：每页 `.ib-*` 元素数、用到的种类数、是否有周期 > 30s 的"假动效"。**只有「全部明显可见」才算自检通过**；以前"全部页面都在动"的说法过松，会放过几乎静止的页面。

注意几种情况检不出来：

- 只有 `.ib-text` 且忘了 `inline-block` → ratio 接近 0
- 幅度调到 `--amp-xs` 以下且没有 F 层 → 会落到"微动不可见"档
- `prefers-reduced-motion` 开启的测试环境 → 全部动画被禁用，属正常，不算问题

参考值（新参数）：F 层光柱 / 光幕 + 背景推镜约 0.03–0.15；只有装饰环约 0.002–0.006（属不合格）。
