# 素材判断与提示词

流程第 2 段。目标：逐页确定素材来源，并按铁律先写提示词再生成。

## 一、逐页素材判断（核心）

**"用户给了图" ≠ "素材齐了"。** 每一页都要单独过一遍判断，不能因为用户给了一张图就默认后面都不缺。

对每一页，按大纲的"素材需求"字段判断：

```
这一页需要视觉素材吗？
├─ 不需要（纯文字/金句）→ 跳过
└─ 需要
    ├─ 用户给的素材能覆盖这一页吗？
    │   ├─ 能（内容对得上、风格搭）→ 直接用（技能做融入+排版）
    │   └─ 不能（缺失/角度不对/风格不搭）→ 继续往下
    │       ├─ 平台支持生图 → 先写生图提示词 → 再生成
    │       └─ 平台不支持生图 → 用内联 SVG 示意图补位
```

判断要点：
- **内容对得上**：这页要"低角度外观"，用户给的是"室内"→ 不覆盖。
- **风格搭得上**：用户给的图是"冷色调写实"，而风格锁是"暖调手绘"→ 不搭，需重生成或降级。

## 二、素材清单.md 的产出格式

```markdown
# <主题> · 素材清单

## 用户素材
| 文件 | 用途 | 覆盖页 |
|---|---|---|

## 待生图（每张先写提示词，确认后生成）
| 页 | 用途 | 提示词(风格锁段+内容段+一致性段) | 状态 |
|---|---|---|---|

## 待 SVG（内联示意图规格）
| 页 | 画什么 | 元素构成 |
|---|---|---|

## 视频
| 文件 | 用途 | 页 |
|---|---|---|
```

## 三、生图铁律（不可违反）

1. **先写提示词，再生成。** 每张待生图，先在素材清单里写好三段式提示词。
2. **母图机制。** 同主题先定母图，后续每张以母图为参照 + 一致性段。
3. **同一物体/产品必须锁一致性。** 多页主体是同一物体/产品/建筑/人物时，先列"固定外观特征清单"（形状/材质/颜色/比例/标志细节），每条提示词共用这份清单，并用母图做图生图参照。禁止每张图长得像不同主体。
4. **每张生成后质检。** 看图确认：①主体一致（对照一致性清单逐项核对）；②无多余文字水印；③风格对齐。不合格→凭提示词重生成。

## 四、SVG 示意图规格

当走"无图版"或"讲逻辑/结构"的页，用内联 SVG。规格要点：
- 线条图配生长动画（描边渐显）；
- 用强调色做重点标记（红点/红线）；
- 尺寸用 viewBox 归一，缩放不变形。

## 五、视频素材

用户提供视频时，用 `<video>` 内嵌：
- 背景视频：`autoplay muted loop playsinline`，铺底 + 同底色渐变遮罩 + 文字压上；
- 局部展示：放页面局部，配播放控制。
