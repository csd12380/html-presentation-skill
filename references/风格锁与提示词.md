# 风格锁与提示词

流程第 1.5 步。目标：在出图之前，先锁定整套演示的视觉规范，让**图片内部**和**HTML 界面**是同一套视觉语言；同时用"明度错开"防止"图白底+页白底"的同化问题。

## 一、风格锁三原则（铁律，写进每一份视觉规范）

1. **色系一致**：图片的色温、饱和度与页面配色同一色系，看起来是"一套"。
2. **明度错开**：图片主体与页面背景之间必须有可感知的明度或色相差。**禁止"图白底 + 页白底"的同化**——否则图片边界消失，视觉上等于没图。
3. **光影定向**：生图提示词固定光位词（如"左前方柔光"），让图片自带方向性阴影，增强立体感和边界识别。

## 二、视觉规范模板

生成 `视觉规范.md`，字段如下：

```markdown
# <主题> · 视觉规范

- 风格预设：深蓝科技 / 米白杂志 / 手绘 / 极简白
- 背景色：<色值>
- 主色：<色值>（大面积）
- 强调色：<色值>（点缀，单页面积 ≤8%）
- 中性色：<色值×3>（文字三级灰阶）
- 材质质感：<纸感/磨砂/玻璃/纯色>
- 光影基调：<黄昏暖光/正午柔光/冷调/无>
- 构图气质：<极简杂志/科技栅格/手绘留白>
- 字体：标题<衬线/无衬线> 正文<无衬线>
- 画布：1920×1080，等比缩放

## 明度错开说明
（一句话说明：背景色和图片主体如何拉开明度/色相）
```

风格预设默认值见 `视觉规范.md`。

## 三、生图提示词三段式

每张生图提示词 = 风格锁段 + 内容段 + 一致性段，三段拼成一条。

### 段 1 · 风格锁段（从视觉规范翻译，固定前缀）

把视觉规范里的配色/材质/光影，翻译成英文风格词，固定作为每条提示词的开头。示例（米白杂志风）：

```
warm off-white minimalist editorial style, soft golden-hour light,
muted warm tones, matte paper texture, clear subject-background separation,
no text, no watermark, no people
```

关键：风格锁段里必须带 **"clear subject-background separation"（主体与背景分离）**，这是"明度错开"在提示词里的落地写法。

### 段 2 · 内容段（这一页要什么）

主体 + 视角 + 构图。示例：

```
low-angle three-quarter view of a white modernist villa
floating on a row of thin steel pilotis
```

### 段 3 · 一致性段（同主题固定）

保证同主题所有图是同一个主体。示例：

```
same building, same materials, same window bands,
same thin pilotis, change only the camera
```

## 四、同一物体 / 产品的一致性（铁律强化）

当多页图像的主体是**同一个物体 / 产品 / 建筑 / 人物 / 品牌形象**时，一致性是最高优先级，必须保证"看的是同一个东西"。

### 判断：什么时候必须锁定一致性

只要满足下面任一条，就必须走"母图 + 一致性锁定"流程：

- 多页围绕**同一个具体物体**（一辆车、一部手机、一栋楼、一个吉祥物）；
- 多页围绕**同一个产品**的不同角度/细节/使用场景；
- 多页反复出现**同一品牌形象或同一人物**。

反例（无需锁定）：每页是不同物体（不同菜、不同景点），只需风格一致即可，不需要"主体一致"。

### 操作：先列"固定外观特征清单"，再生成

生成前，先明确写出这个主体的**不可变特征**，写进 `素材清单.md`，作为每条提示词的一致性段的依据：

```
【主体一致性清单】<主体名>
- 整体形态：<轮廓/体量>
- 材质：<材质与质感>
- 颜色：<主色 + 标志性配色>
- 比例：<关键比例关系>
- 标志性构件/细节：<一眼能认出的特征>
```

然后每条生图提示词的"一致性段"，用清单里的词固定写死，例如：

```
same <主体>, same shape, same material, same color scheme,
same proportions, same signature details, change only the camera
```

### 强制手段：以母图为参照图

1. 先选/先生成一张最接近目标外观的图作为**母图**（master）。
2. 后续每张用生图工具的**图生图**能力：把母图作为参照图（image1 参数），并设 `input_fidelity` 为中等偏上（如 medium）。
3. 提示词只改"机位 / 光线 / 时间 / 环境"，禁止改主体本身的描述。
4. 每张生成后**看图质检**：对照清单逐项核对，主体不一致 → 凭提示词重生成，直到一致。

### 质检要点（对照清单逐项核对）

- 形状/轮廓是否一致（不能一张圆角一张直角）；
- 材质/颜色是否一致（不能一张哑光一张亮面）；
- 比例是否一致（不能一张长一张扁）；
- 标志性细节是否都在（不能丢了 logo、丢了标志性构件）。

### 踩过的坑

- **不锁一致性，每张都像新主体**：曾生成 4 张"同一栋别墅"，结果像 4 栋不同的楼。根因是每条提示词独立描述主体，没有共用一份固定特征清单，也没用母图做参照。锁定后 10 张即同一栋楼。

## 五、母图机制

1. 同主题的多张图，先挑/先生成一张作"母图"（master）。
2. 后续每张以母图为参照图（image1 参数）+ 一致性段，只改机位/光线/时间。
3. 每张生成后都要看图质检：主体是否一致、是否带水印、风格是否对齐。

## 六、提示词先落盘（铁律）

每张图的提示词，先在 `素材清单.md` 里写好、检查完，再调生图工具。禁止跳提示词直接生图。好处：可审查、可重跑、可保证一致性。
