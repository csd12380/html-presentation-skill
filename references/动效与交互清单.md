# 动效与交互清单

流程第 4 段。成品必须是"会动、能交互"的高端演示站，不是静态翻页。

## 〇、翻页方式（硬性约定）

成品**不显示任何翻页按钮/控件**，翻页统一用键盘 + 鼠标滚轮。

- **禁止出现**：上一页/下一页按钮、左右箭头按钮、可点击的页码圆点、翻页图标等任何翻页 UI 元素。
- **翻页方式**：
  - 键盘：`←` / `→`（左右）与 `↑` / `↓`（上下）都可翻页；`PageUp` / `PageDown` / `空格` 同样有效；`Home` / `End` 跳首末页。
  - 鼠标滚轮：**向下滚 = 下一页，向上滚 = 上一页**，与页面切换动画方向一致。滚轮是必备项，不能只有键盘。
- **可保留**：角落一个**不显眼、不可点击**的页码提示（如小字"3 / 11"），仅作定位参考，不得是翻页控件。位置优先左下或右下，**必须避开角标、图注等元素**，被遮挡就换到另一角。
- **实现要点**：键盘用 `keydown`；滚轮用 `wheel` 且必须 `{passive:false}`。不渲染 prev/next 按钮和 dots 圆点。

> 目的：让成品看起来像"网页作品"而非"PPT 播放器"，翻页靠演讲者用键盘或滚轮控制，界面更干净、更高级。

### 滚轮翻页的四个坑（照抄下面的代码就都避开了）

1. **滚一格翻三页**：触控板/滚轮一次操作会连发几十个 `wheel` 事件，必须转场锁定（触发后 ~650ms 内忽略后续事件）。
2. **惯性尾巴甩页**：手势停下后仍有残余事件，超过 140ms 没有新事件就清零累加器。
3. **轻碰就翻页**：单次 `deltaY` 差异极大（滚轮一格≈100，触控板一划可累计数百），用**累计值 + 阈值**判断，不用单次值。
4. **页内可滚动区被抢**：页内有滚动容器时，先用 `[data-scroll]` 标记它，滚到边界才翻页。

```js
/* 翻页：键盘 + 滚轮，无任何按钮 */
var cur = 0, N = slides.length, lockUntil = 0, acc = 0, lastWheel = 0;

function go(i){
  if(i < 0 || i >= N || i === cur) return;
  slides[cur].classList.remove('on');
  cur = i; activate(cur);
  lockUntil = Date.now() + 650;          // 坑1：转场期间锁住
}

document.addEventListener('keydown', function(e){
  var k = e.key;
  if(k === 'ArrowRight' || k === 'ArrowDown' || k === 'PageDown' || k === ' '){ e.preventDefault(); go(cur + 1); }
  else if(k === 'ArrowLeft' || k === 'ArrowUp' || k === 'PageUp'){ e.preventDefault(); go(cur - 1); }
  else if(k === 'Home'){ e.preventDefault(); go(0); }
  else if(k === 'End'){ e.preventDefault(); go(N - 1); }
});

document.addEventListener('wheel', function(e){
  var now = Date.now();

  // 坑4：页内可滚动区先滚内容，到边界才翻页
  var box = e.target.closest ? e.target.closest('[data-scroll]') : null;
  if(box){
    var top = box.scrollTop, max = box.scrollHeight - box.clientHeight;
    if((e.deltaY > 0 && top < max - 1) || (e.deltaY < 0 && top > 1)) return;
  }

  e.preventDefault();
  if(now < lockUntil) return;                 // 坑1
  if(now - lastWheel > 140) acc = 0;          // 坑2：停顿即清零
  lastWheel = now;

  acc += e.deltaY;                            // 坑3：累计 + 阈值
  if(acc > 50){ acc = 0; lockUntil = now + 650; go(cur + 1); }
  else if(acc < -50){ acc = 0; lockUntil = now + 650; go(cur - 1); }
}, {passive:false});
```

## 一、动效（视觉）

| 动效 | 用途 | 实现要点 |
|---|---|---|
| 整页入场 | 翻页切换 | 上浮 + 淡入，600ms，`cubic-bezier(.22,1,.36,1)` |
| 子元素错峰 | 一页内元素依次出现 | 每个元素设递增 `animation-delay`（约 100–120ms 步进） |
| 图片推镜 | 图片入场 | 图片 `scale(1.06)→1`，1500–1700ms |
| SVG 描边生长 | 线条/箭头/流程图"画出来" | `stroke-dasharray/dashoffset` 动画，长度用 `getTotalLength()` |
| 数字滚动 | 关键数字/数据 | `requestAnimationFrame` 从 0 滚到目标值，1200ms |
| 悬停上浮 | 可点元素反馈 | `translateY(-3px)` + 阴影 |
| 翻走重置、回来重播 | 保证动画可重复 | 离开页时重置动画状态，回来重播 |

### 1.1 环境态循环（页面不切换，画面一直在动）

上面那张表全是**一次性**动画：跑完就停，页面只剩静止画面。真正像视频的地方在于**环境态**——入场结束后，背景、图片、光影、标题继续各自动，观众不翻页也能一眼看见画面在动。

> **可见性第一。** 早期把推镜设成 48s / 1.07 倍、位移 1.5%，1 秒只走 0.6px：验活测得到像素差，人眼却完全看不出。这不是"高级的克制"，是没做出来。默认参数已改为**肉眼明显可见**（周期 5–28s、位移 3–9%、缩放 1.10–1.30、明暗跨度 ≥0.4），不要再往回压。

**分层铁律（最容易出 bug 的地方）**

入场动画和环境态动画都要改 `transform`，落在同一个元素上会互相覆盖，表现为"动效闪一下就不动了"。必须分两层：

```html
<!-- ✅ 外层管入场，内层管环境态 -->
<div class="a" style="--d:.3s"><img class="ib-img" src="assets/a1.jpg"></div>
<h2 class="a" style="--d:.18s"><span class="ib-text">页面大标题</span></h2>

<!-- ❌ 一个元素两套动画，必炸 -->
<h2 class="a ib-text" style="--d:.18s">页面大标题</h2>
```

**接入三步**

1. 把 `templates/环境态动效.css` 整段粘进页面 `<style>` 末尾。文件末尾自带「静止态预置」，不用再手写 0% 对齐规则。
2. 按 `references/环境态动效库.md` 的三速节奏给每页挑 **3–4 个类**：慢速（14–28s）铺底、中速（8–11s）氛围、快速（≤5s）点题，**再加一个 F 层强可见主运动**（`.ib-beam` / `.ib-particles` / `.ib-maskflow` / `.ib-edge` / `.ib-wave` / `.ib-orbit`）。库共 40 种，分 A–F 六层，附参数变量表和 7 套主题配方。
3. 相邻页换搭配，11 页至少用 8 种不同组合。讲解页 / 交互页 / 数据页也要有主运动，只是把动效放在背景层、不动数字和说明文字。

**四条必须记住的**

- **0% 关键帧等于入场结束时的静止状态**，否则第 1.6 秒会跳一下；CSS 末尾的「静止态预置」已统一处理，改幅度时那段要同步改。
- **大幅动的是背景、图片、光影和装饰，不是正文。** 标题可到 10–16px 位移，正文、图注、页码、数据标签一律不加。`.ib-text` / `.ib-wave` 挂 `span` 时必须 `display:inline-block`（CSS 已内置），否则 `transform` 无效。
- **一页 3–4 个动效，上限 5**，每个 `will-change` 都吃显存。
- **周期不得超过 28s。** 48s / 90s 那种"慢到看不见"的设定一律不用；`check.py` 会直接把 >30s 的动画标成假动效。

**翻走重置、回来重播**：环境态动画全部挂在 `.slide.on` 下，翻页时 `.on` 一移走自动停，回来重新挂上从 0% 重播，不需要额外写 JS。系统开了"减少动态效果"时 CSS 会自动全停。

**自检（必跑）**：`scripts/check.py` 在入场结束后隔 2.0s 截两帧比对像素差，并按三档判定：`ratio < 0.002` 静止 ⚠、`0.002–0.012` **微动不可见 ⚠（仍算不合格）**、`≥ 0.012` 明显可见 ✅。同时输出每页动效数、种类数、最长周期。**只有全部「明显可见」才可交付**。旧版阈值 0.0002 太松，会把几乎静止的页面判合格——这正是"加了动效却看不见"的根因之一。

## 二、交互（行为）

**原则：每页至少一个可点/可拖/可滑的交互点，不能只有翻页。**

四类通用交互：

| 交互 | 用法 | 场景 |
|---|---|---|
| 对比切换 | 点按钮切换两种状态/两套图 | A/B 对比 |
| 展开详情 | 点卡片浮出解释 | 详情 |
| 拖拽滑块 | 拖滑块画面跟着变 | 分解程度、时间轴 |
| 分步播放 | 点按钮/键盘一步步揭开 | 流程 |

## 三、三维

两种选型，按需求：

| 选型 | 适用 | 依赖 | 文件体积 |
|---|---|---|---|
| CSS 3D 分层爆炸 | "拆开看内部" | 零依赖 | 单文件，百行内 |
| Three.js | "转着看外观"真实模型 | 需内联库 | 单文件 1–3MB |

CSS 3D 分层要点：
- 层用 `transform:translateZ(calc(var(--z)*var(--sp)))`，`--z` 由属性选择器 `.layer[data-z="3"]{--z:3}` 注入（写在 data-z 属性上 `var(--z)` 取不到）；
- 层距 `--sp` 过大会把顶层推出画面，需按层高实测上限；
- 支持：拖拽旋转、点层高亮、分解按钮、分解滑块、复位。

## 四、动效克制原则

1. 全场只用 **1–2 条缓动曲线**，不混用。
2. 入场 750ms、转场 600ms，时长统一。
3. 动效服务于"讲清楚"，不做纯炫技的无效动画。
4. 禁止 autoplay 大段动画抢戏；动画要能重播、能打断。
