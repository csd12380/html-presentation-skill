# 视觉规范

流程第 3 段（HTML 组装）的样式依据 + 第 1.5 段风格锁的默认模板来源。

## 一、高端网站硬指标（"高端"的可验收标准）

"高端"不是形容词，落到这些硬指标上，做得到才叫高端：

1. **栅格对齐**：每页元素对齐统一边距（左右 120px、上下 96px），不随意摆放。
2. **留白充足**：单页文字 ≤60 字，图/图形/数据占主体，文字做点睛。
3. **一套字体系统**：标题（衬线或加粗无衬线）+ 正文（无衬线），字号阶梯固定。
4. **动效克制统一**：入场 750ms 同一条缓动，转场 600ms，不混用多套曲线。
5. **每个元素有职责**：图、图形、数据、动画各司其职，禁止纯装饰堆砌。
6. **编辑细节**：细线分隔、强调色点缀、角标、图注、页码——这些"编辑细节"是高级感来源。

## 二、画布与缩放（通用约定）

- 画布固定 **1920×1080**，所有尺寸用 px，禁止 vw/vh 做尺寸。
- 用 JS 算 `scale = min(innerWidth/1920, innerHeight/1080)` 整体缩放，设计稿和成品 1:1。
- 字号阶梯：**120 / 66 / 36 / 26**（大标题 / 页标题 / 正文 / 图注），关键数字可单独放大到 210。

### 字号下限（铁律，防"字太小看不见"）

画布固定后会被 `scale` 缩放，窗口越小字越小，因此**字号必须留足余量**，否则缩小后不可读。

- **最小字号不得低于 22px**（图注、标签、页码、SVG 内文字这一类辅助文字的下限）。
- **正文（正文/说明文字）≥ 36px**，页标题 ≥ 66px，大标题 ≥ 120px。
- **SVG 内的 `<text>` 字号 ≥ 28px**（SVG 随 viewBox 缩放，本身就会再缩小，起点必须更大）。
- 判断标准：**投影到大屏、观众离 5 米仍能看清**，而不是"在电脑屏幕前能看清"。
- 自检时若发现任何文字"勉强能看清"或"偏小"，一律放大一档，不要踩下限。

> 反面教训：曾把正文设 28px、图注设 20px、SVG 文字设 22px，画布缩放后"界面很大、字小到看不见"。根因是只按 1920 设计稿定字号，忽略了缩放后的实际显示尺寸。字号档位已在上面整体上移。

## 三、四套风格预设

### 预设 A · 深蓝科技（默认，符合通用商务/科技主题）

```
背景 #0F2B4C（深蓝）  主文字 #F2F4F7  强调 #C8352B（红）
辅助 #4A6B8A  灰 #8FA3B8
材质：纯色 + 微光晕  光影：冷调  构图：科技栅格
字体：标题加粗无衬线，正文无衬线
```

### 预设 B · 米白杂志（文化/建筑/设计/人文主题）

```
背景 #F6F2EA（米白）  主文字 #1B1B1B  强调 #D9442E（亮红） 编号 #8B3A3A（砖红）
辅助灰 #96918A  细线 #D8D2C6
材质：纸感  光影：黄昏暖光  构图：极简杂志
字体：标题衬线宋体，正文无衬线
```

### 预设 C · 手绘风（教学/趣味/低龄主题）

```
背景 #FBF7F0  主文字 #2B2B2B  强调 #E2574C
材质：手绘线条 + 纸感  光影：无  构图：手绘留白
字体：标题圆润黑体，正文无衬线
```

### 预设 D · 极简白（汇报/数据/商务正式主题）

```
背景 #FFFFFF  主文字 #111111  强调 #1A73E8（或 #C8352B）
辅助灰 #757575  细线 #E5E5E5
材质：纯白  光影：无  构图：极简栅格
字体：标题加粗无衬线，正文无衬线
```

## 四、选择规则

- 用户指定风格 → 用用户指定；
- 未指定 → 按主题类型选：商务/科技→A，文化/建筑/设计→B，教学趣味→C，正式汇报→D；
- 默认（不确定时）→ A 深蓝科技。

## 五、配色落地注意

- **强调色单页面积 ≤8%**：只做点缀（短线、角标、数字、高亮），不大面积铺。
- **涨红跌绿**：涉及金融/股票涨跌时，涨=红、跌=绿（中国约定），与本技能强调色无关。
