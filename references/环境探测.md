# 环境探测

流程第 0 步。目标：在生成任何东西之前，先搞清楚两件事——**当前平台能不能生图**、**用户给了什么素材**。结论决定后续走"有图版"还是"无图版"。

## 一、探测生图能力

1. 用 ToolSearch 查 `ImageGen` 工具是否可用。
2. 结果二选一：
   - **支持生图** → 流程走"有图版"，第 2 段可调用 ImageGen 生成实拍/渲染图；
   - **不支持生图** → 流程走"无图版"，第 2 段所有"待生图"降级为"内联 SVG 示意图"或"纯排版"，全程离线不依赖外部服务。

> 注意：不要凭记忆假设平台能不能生图，必须当场探测。同一个技能可能在不同平台运行，探测是让技能"随处可用"的关键。

## 二、盘点用户素材

启动时确认用户是否提供了素材，逐项登记：

| 素材类型 | 用途 | 处理方式 |
|---|---|---|
| 图片（照片/渲染图/logo/图标） | 直接用于页面 | 登记路径，第 2 段优先使用 |
| 视频 | 背景 / 局部展示 | 用 `<video>` 内嵌，登记路径 |
| 品牌色 / logo / 规范 | 风格锁依据 | 纳入视觉规范 |
| 无素材 | 全靠生成 | 走生图或 SVG |

## 三、探测截图能力（用于自检）

1. 检查是否有浏览器自动化能力（Playwright / 浏览器 MCP）。
2. 有 → 第 5 段跑 `scripts/check.py` 逐页截图；无 → 自检改为"人工预览 + 几何估算"。

## 四、输出

探测结束后，在对话里给用户一句明确结论，例如：

> 当前平台【支持 / 不支持】AI 生图；您提供的素材有【N 张图 / N 个视频 / 无】；成品将走【有图版 / 无图版】流程。

并据此决定后续每页的素材来源策略。
