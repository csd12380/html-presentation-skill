# 融入方式库

流程第 3 段的核心。图片"长"在页面里，靠的不是一张好看的图，而是图片**边缘、形状、层级**和页面发生的交接关系。

铁律：**每页图片必须用下表的一种手法做融入，禁止裸贴矩形图；同一种手法不要在连续两页重复。**

## 14 种融入手法

| # | 手法 | 适用内容 | 核心代码要点 |
|---|---|---|---|
| 1 | 全幅出血 + 左渐变遮罩 | 氛围页/封面/结尾 | 图铺满整页，左侧叠同底色 `linear-gradient(90deg, 底色97%→透明)`，文字压雾化区 |
| 2 | 全幅出血 + 右渐变遮罩 | 氛围页（文字在右） | 同上，方向反转 `270deg` |
| 3 | 底部/单边羽化渐隐 | 通栏大图、横向场景 | `mask-image:linear-gradient(180deg,#000 60%,transparent)` + 底部同色渐变叠加 |
| 4 | 斜切异形出血 | 外观、有方向感的内容 | `clip-path:polygon(0 0,100% 4%,96% 100%,0 100%)` |
| 5 | 拱形 / 大圆角裁切 | 文化/人文/柔调内容 | `border-radius:50% 50% 0 0 / 34% 34% 0 0` |
| 6 | 圆形裁切 + 圆环 | 焦点/象征内容 | `border-radius:50%` + 外圈 `::after` 环 |
| 7 | 双段错位拼接 | 讲"贯穿/连续/延伸" | 一张图裁两段，`clip-path` 斜切后错位，制造"断开再延续" |
| 8 | 底衬色块叠印 | 数据/几何/秩序内容 | 一块浅色块 `left:-26px;top:-26px` 垫图后错位露出，图加投影 |
| 9 | 竖条 / 角标压角 | 封面、强调 | 图边压一条强调色竖条或角标，图"插"进色块 |
| 10 | 局部出框 | 人物/建筑主体 | 图裁切后让主体用负 margin 探出裁切线，父容器 `overflow:visible` |
| 11 | 一图裁三块横向散开 | 叙事节奏/过程 | 一张图裁 3 块，`transform` 横向错位，配悬停聚拢 |
| 12 | 色块开窗 | 强调局部 | 一块色块叠图，用圆孔/方孔 `mask` 或裁切露出图的关键局部 |
| 13 | 视频背景遮罩 | hero 区/开场 | `<video autoplay muted loop>` 铺底 + 渐变遮罩 + 文字压上 |
| 14 | 悬停局部放大 | 细节展示 | `img` 默认 `scale(1)`，`frame:hover img{scale(1.08)}`，配 `object-position` 移动 |

## 融入手法的三个技术要点

1. **羽化用 mask**：`-webkit-mask-image` / `mask-image` 的 `linear-gradient`，让图片边缘渐隐进背景。
2. **异形用 clip-path**：`polygon()` 斜切、出血、开窗。
3. **叠印色块要垫对层级**：色块用 `::before` 放在容器（`.shot::before`）而非 `.frame::before`——`.frame` 是 `position:relative` 会建层叠上下文，吞掉 `z-index:-1`，导致色块被图盖住。

## 手法选择规则（按内容类型自动映射）

| 内容类型 | 首选手法 |
|---|---|
| 封面/结尾氛围 | 1 / 2（全幅遮罩）或 13（视频） |
| 外观/场景实拍 | 3 / 4 / 9 |
| 讲逻辑/结构/关系 | 内联 SVG（非图片手法） |
| 数据/几何/秩序 | 8（叠印） |
| 贯穿/连续/延伸 | 7（双段错位） |
| 焦点/象征 | 6（圆形+环） |
| 人物/主体特写 | 10（局部出框） |
| 过程/叙事节奏 | 11（一图三裁） |

## 已踩过的坑（务必记住）

- **SVG `rect` 的 `getTotalLength()` 返回 0**，做描边生长动画时整个图形会消失。画线动画用 `line`/`path`；矩形要描边生长就写成等周长 `path`（`M..h..v..h..z`）。
- **"图白底 + 页白底"同化**：图片边界消失。靠风格锁"明度错开"解决，不是靠融入手法解决。
- **全幅遮罩的渐变方向**：文字在哪侧，遮罩实区就在哪侧；渐变从"实"到"透明"，宽度约 40–55%。
